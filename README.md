BookNest: Where Stories Nestle

Welcome to BookNest, a digital haven for book enthusiasts to explore, borrow, and manage their literary treasures. Whether you're an avid reader or a casual browser, BookNest offers a seamless experience to discover and enjoy a vast collection of books.

📚 About

BookNest is a user-friendly platform designed to:

Browse a diverse collection of books across various genres.

Borrow books effortlessly with a few clicks.

Manage your borrowed books and reading history.

Admin Dashboard for efficient library management.

This project is developed as part of a learning initiative and aims to provide a practical solution for book management.

🚀 Features

User Authentication: Secure login and registration system.

Book Catalog: Explore books by categories, authors, and titles.

Borrowing System: Easily borrow and return books.

Admin Panel: Manage books, users, and borrow records.

Responsive Design: Optimized for both desktop and mobile devices.

📥 Installation

To set up BookNest locally:

Clone the repository:

git clone https://github.com/VasieddyHemaNagaSri/booknest-where-stories-nestle.git


Navigate into the project directory:

cd booknest-where-stories-nestle


Install frontend dependencies:

cd frontend
npm install


Install backend dependencies:

cd ../backend
npm install


Set up environment variables:

Create a .env file in the backend directory.

Add the following variables:

PORT=5000
MONGO_URI=your_mongo_database_uri
JWT_SECRET=your_jwt_secret_key


Start the backend server:

cd backend
npm start


Start the frontend server:

cd frontend
npm start


The application should now be running on http://localhost:3000.
